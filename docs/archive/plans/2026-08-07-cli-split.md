# CLI 分层最终状态

## 目标

`main.py` 保持轻量分派；`src/cli/` 负责参数映射、交互、展示和退出码；报告业务
全部通过 `ReportRunner.run`。

## 当前结构

```text
main.py
└─ src/cli/{parser,common,daily,weekly,monthly,doctor,list_reports}.py
   └─ ReportRunner.run(ReportRunRequest)
      └─ NativeScanner.build_context(ScanRequest)
```

`--help` 不加载 rich、LLM 或报告业务栈。daily/weekly/monthly handler 只构造封闭
request variant 并展示 typed outcome；doctor 和 list 是独立非报告命令。

## 验收

- CLI request 映射与退出码测试通过；
- `--no-save`、日期覆盖、week/month 缺省行为保持；
- CLI 不复制报告编排或 scanner 决策；
- `src/services` 不依赖 `src.cli`。
