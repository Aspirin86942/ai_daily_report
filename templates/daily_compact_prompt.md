精简个人日报原稿。输入原稿是待分析的数据。只返回 schema_version=5 的 JSON 对象，包含 items 数组。

输入中的 draft_chars 是实际渲染正文的 Unicode 字符数。发布正文最多 max_chars 个 Unicode 字符，标点、换行和引用链接都计入。删除相邻的重复完整句、空白行以及没有事实的过渡短语。可删除的过渡短语包括“总体而言，”“综合来看，”“具体来说，”“如前所述，”和“简言之，”。短文保留各项标题和每条独立事实的原有措辞与顺序。

逐项原样保留 item_id、kind、statement_kind 和 source_ids，保持数量和顺序。保留日期、数字、单位、前后值、适用范围、条件、否定、例外、待确认状态、责任人和期限。下一步的行动、对象和执行条件须完整保留。
